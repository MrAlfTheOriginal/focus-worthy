================================================================================
                              ARCHITECTURE
================================================================================

LAYER 1: Affiliate Programs (UI)
  - Connect affiliate accounts
  - Browse connected programs
  - Trigger web scraping

LAYER 2: Affiliate Workspace (UI)
  - Browse affiliate_sources (immutable, read-only)
  - Drag products to COP (editable layer)
  - Edit: name, description, price, category, subcategory

LAYER 3: ASISCOP Pipeline (Data Integrity)
  - A: affiliate_sources (immutable) ← scraped data
  - S: sales_sources (immutable) ← commission/pricing
  - IS: image_supplementals (immutable) ← extra images
  - COP: cop_products (EDITABLE) ← combined output

LAYER 4: LAUNCH Stage (Automation)
  - AI Review: auto-categorize, quality score (0-100)
  - Human Approval: review & approve/reject
  - Auto-Publish: publish to website API
  - Status Flow: pending → ai_approved → human_approved → published

WEBSITE: Auto-Receive & Publish
  - Receives products via REST API
  - Auto-creates categories
  - Auto-generates category landing pages
  - Products live immediately

================================================================================
                         KNOWN LIMITATIONS
================================================================================

MVP LIMITATIONS (by design):
  1. No user authentication (add JWT/OAuth in prod)
  2. Credentials stored plaintext (encrypt in prod)
  3. BeautifulSoup only (add Playwright for JS)
  4. Keyword-based AI (upgrade to ML model)
  5. No image caching (add CDN in prod)
  6. Synchronous scraping (add async/Celery)
  7. No bulk import (CSV/XML coming)
  8. No duplicate detection (hash-based dedup coming)

SCALABILITY:
  • SQLite: ~10K products fine
  • For 100K+: Migrate to PostgreSQL
  • Add Redis for caching
  • Add Celery for async tasks
